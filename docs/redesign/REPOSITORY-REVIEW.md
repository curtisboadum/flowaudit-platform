# Requested repositories and starred library

The authenticated GitHub account exposed **445 starred repositories** during planning and again during implementation. Every accessible entry was inventoried by name, description, language, update and license metadata. The complete metadata list is `starred-repositories.json`; approximately 500 was the user’s estimate. This does not mean 445 codebases were security-audited or installed.

Usefulness triage prioritised design systems, frontend quality, motion, accessibility, conversion copy, pricing and testing. Unrelated agent frameworks, video-generation research, scraping stacks, trading tools and backends were not added to a marketing website. Adding them would increase maintenance without strengthening this experience.

| Source | Relevant principle | Application |
|---|---|---|
| [design-md-chrome](https://github.com/bergside/design-md-chrome) | Explicit foundations and component/state documentation | Original `DESIGN.md`; direct browser/source inspection. No extension install or cloned competitor tokens. |
| [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) | Compare design systems as references | Original restrained editorial identity; no wholesale template. |
| [reverse-skill](https://github.com/zhaoxuya520/reverse-skill) | Reverse-engineering workflow | Screened in planning; security-oriented routing is unsuitable for website design research. No third-party penetration testing or execution. |
| [pricing-strategy](https://github.com/emotixco/claude-skills-founder) | Scope, buyer value, packaging and cost-aware testing | Private pricing hypotheses with delivery/usage boundaries; no public invented guarantees or statistics. The user’s command URL had moved to a skill path. |
| [design-motion-principles](https://github.com/kylezantos/design-motion-principles) | Motion must explain a relationship | restrained transition and reduced-motion rules. |
| [taste-skill](https://github.com/Leonxlnx/taste-skill) | Specific visual choices, responsive polish | unequal composition, actual evidence, strong typography and mobile review. |
| [vercel agent-skills](https://github.com/vercel-labs/agent-skills) | Performance-aware React practices | static public pages, native media, bounded client components, production-build testing. |
| [marketingskills](https://github.com/coreyhaines31/marketingskills) | Clear offer and conversion friction review | service-aware CTAs, optional VSL, contextual booking, scoped quotes. |
| [scroll-craft](https://github.com/nateherkai/scroll-craft) | Deliberate scroll presentation | studied as a reference; no heavy scroll engine added. |

Readme/skill review was targeted to relevant candidates. Starred status is neither endorsement nor permission to install arbitrary software. No new third-party repository code was executed. Added testing packages came from the normal npm registry. Production dependencies were audited and patched separately.

Existing Codex and OpenCode work was read during planning and implementation to establish the newest website baseline and film handoff. A separate live voice/outreach implementation had unresolved latency and interruption QA; its state was not presented as verified public capability or altered by this redesign. The newer completed-film handoff superseded older task summaries that called production blocked.
